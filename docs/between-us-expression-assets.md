# Between Us expression asset brief

Status: artwork required. The pack manifest is deliberately hidden from production until every published item has provenance-reviewed animation and static fallback files.

## Delivery contract

- Canvas: transparent 512×512 px, except `across-the-miles` at 640×512 px.
- Safe area: keep meaningful artwork within the central 88% of the canvas.
- Animated delivery: transparent animated WebP or another format proven by physical-device tests in the installed renderer; no opaque video fallback.
- Static fallback: lossless transparent WebP or PNG using the identical crop and silhouette.
- Motion: one 160–600 ms local flourish, then settle; seamless continuous loops are not desired.
- Palette: near-black teal compatibility plus champagne, coral, rose, ivory and lavender accents. Edges must remain legible on both Betweener wallpapers.
- Lighting: soft satin forms, consistent upper-left key light, restrained highlights, no heavy glitter or ubiquitous gold.
- Provenance: source files, creator/licence record, export checksum and asset version are required before enabling an item.

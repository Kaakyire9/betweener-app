# Retired standalone Connect harness

Retained for offline regression tests and historical evidence. It is not the
current product-testing workflow. The old launcher now exits with a retirement
notice and does not start Metro, ADB, an app or sensors.

Current testing uses the existing Betweener Staging development clients and root
Metro. See [Connect](../../docs/betweener-connect/README.md).

The original launcher is preserved byte-for-byte in the
[retired-source archive](../../docs/betweener-connect/archive/retired-code/manifest.json).
